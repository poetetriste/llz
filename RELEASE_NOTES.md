# llz 0.2.0 — reproducibility and integrity release

## Главное

- Главный результат сохранён: 1 251 867 Б русской Википедии → 77 590 Б
  payload, 16,13×, byte-exact, CRC32.
- Исправлено поле scale в контрольном LLZ2 (`2^16` → фактическое `2^28`);
  payload не изменён.
- `341,26×` теперь строго обозначается как entropy estimate на зацикленном
  самосгенерированном тексте.
- Для того же файла получен настоящий круг: 147-Б payload = 267,19×;
  полный LLZ3 = 324 Б = 121,23×, byte-exact, CRC32.

## LLZ3

Новый контейнер сохраняет:

- immutable revision модели;
- dtype/device/compile и block;
- версии Python/PyTorch/Transformers/NumPy;
- token count, payload size и CRC32.

LLZ1 и LLZ2 остаются читаемыми.

## Исправления

- Исправлен кэш при переключении между моделями в одном процессе.
- Внешние параметры больше не проверяются удаляемыми `assert`.
- Обрезанные и противоречивые контейнеры отклоняются до загрузки модели.
- CLI не пишет повреждённый результат при CRC mismatch без явного override.
- HTTP-сервис ограничивает body/token count и возвращает 422 при CRC mismatch.
- Checkpoint большого прогона привязан к SHA-256 входа и сохраняется атомарно.
- `fetch_corpus.py` больше не требует незаявленный пакет `requests`.
- Benchmark теперь отдельно показывает payload и полный контейнер.

## Доказательная база

- точный Wikipedia corpus и отдельное CC BY-SA уведомление;
- исправленный главный LLZ2;
- самосгенерированный corpus, LLZ3 и JSON протокола прогона;
- manifest с размерами, SHA-256, моделью, профилем и CRC32;
- model-free unit tests и модельные Unicode/edge-case tests.
